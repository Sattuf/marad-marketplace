# خطة «النادي»: متاجر ناشئة مميزة، مفحوصة رياضياً، لمشتركين — Club Plan

> 2026-11-27 · بقرار صاحب المشروع. يكمّل `PIVOT_PLAN.md`: نفس محرك القيمة (§4 هناك)، لكن **المصدر** متاجر ناشئة
> ومميزة نكتشفها ونفحصها، لا المنصات الكبيرة. يتقدّم على PIVOT_PLAN §5 (البحث) و§6 (الدخل) عند التعارض.

## 1. الفكرة في سطرين
نكتشف متاجر ومواقع ناشئة أسعارها جيدة، نفحص موثوقيتها وأسعارها بأرقام، ونقدّم الأفضل منها لمشتركي «نادي معرض»
مع **خصومات حصرية للأعضاء** نتفاوض عليها مع المتاجر. المقارنة الأساسية مجانية؛ النادي هو المدفوع.

## 2. خط الإنتاج (Pipeline) — من «لا نعرف المتجر» إلى «نعرضه للمشترك»

```
اكتشاف → فحص أولي (بوابات حمراء) → تقييم بالأرقام → تواصل وموافقة → ربط البيانات → مراقبة مستمرة → (طرد إن ساء)
```

### 2.1 الاكتشاف (Discovery)
| المصدر | الطريقة | ملاحظة قانونية |
|---|---|---|
| بحث ويب منهجي لكل دولة × فئة | استعلامات مُعدّة سلفاً (مثل «متجر إلكترونيات أونلاين دمشق توصيل») يُنفّذها الوكيل في جلسات بحث، كل نتيجة تُسجَّل بمصدرها | قراءة صفحات عامة يدوياً للبحث، لا سحب آلي |
| خرائط الأعمال | بحث أماكن (متاجر فعلية لها موقع) لكل مدينة | بيانات عامة للعرض فقط |
| مجتمعات وفعاليات | منتديات التجارة الإلكترونية (مثل Syria E-commerce Forum / Tajir.Store)، مجموعات تلغرام وفيسبوك التجارية، صفحات إنستغرام وتيك توك | التواصل بشري |
| «رشّح متجراً» داخل التطبيق | المستخدم يرشّح، ويحصل على شهر مجاني إن قُبل المتجر | يُسجَّل المرشِّح |
| «انضم كمتجر» | نموذج للمتجر نفسه | موافقة صريحة من البداية |

**الهدف لكل دولة في الجولة الأولى:** 150 مرشحاً → 40 بعد الفحص → 15 في النادي.

### 2.2 بوابات حمراء (رفض فوري، قبل أي حساب)
- لا وسيلة تواصل حقيقية (هاتف/عنوان)، أو لا سياسة إرجاع، أو الدومين/الحساب عمره أقل من 3 أشهر بلا سجل تجاري.
- يطلب الدفع بتحويل شخصي فقط مع أسعار «خيالية».
- **سعر شاذ:** أرخص من الوسيط المرجعي بأكثر من `3·MAD` (انظر 3.2) → «مشبوه»، لا «صفقة».
- بلاغات احتيال علنية متعددة.

### 2.3 التواصل والموافقة
المتجر يوقّع اتفاقاً بسيطاً: يسمح لنا بقراءة منتجاته وأسعاره، يقدّم خصم نادٍ (مثلاً 5–10% أو شحن مجاني)، ويقبل أن نطرده إن ساء
مستواه. **التواصل بشري** (صاحب المشروع/فريقه)؛ الوكيل يجهّز القائمة والرسائل بالعربية والتركية.

### 2.4 ربط البيانات (بموافقة المتجر فقط)
| حالة المتجر | الربط |
|---|---|
| WooCommerce | واجهة المنتجات القياسية بمفتاح قراءة فقط يعطيه المتجر |
| Shopify | واجهة المنتجات القياسية للمتجر |
| ملف منتجات | CSV/XML بصيغة Google Merchant (رابط ثابت يتحدث) |
| بلا تقنية (إنستغرام/واتساب) | جدول بسيط مشترك أو لوحة إدخال في «بوابة المتجر» |

## 3. الفلترة الرياضية

### 3.1 درجة الموثوقية T (0–1)
```latex
T = \sigma\Bigl(\sum_i w_i x_i - b\Bigr)
```
مؤشرات `x_i` (كل منها 0–1): عمر المتجر، وجود سجل تجاري، وضوح الاتصال، سياسة إرجاع، الدفع عند الاستلام، التقييم المعدَّل (3.3)،
حضور اجتماعي حقيقي (تفاعل لا متابعين فقط)، **اختبار المتسوق الخفي** (رسالة سؤال: زمن الرد وجودته)، تغطية التوصيل.
الأوزان `w_i` تبدأ يدوية (موثّقة في `club/weights.json`) وتُعاد معايرتها كل 3 أشهر من نتائج فعلية (شكاوى/إرجاعات).
**شرط الدخول: `T ≥ 0.7`.**

### 3.2 مؤشر تنافسية السعر C
لكل منتج `j` في سلة المتجر مع سعر مرجعي `R_j` (وسيط السوق من مصادرنا ودراسة السلة):
```latex
C = \operatorname{median}_j \left(\frac{L_j}{R_j}\right)
```
`L` السعر الواصل (PIVOT_PLAN §4.1). `C < 1` يعني أرخص من السوق. **كشف الشذوذ** بالوسيط والانحراف المطلق للوسيط (MAD) لأنه
لا يتأثر بالقيم المتطرفة:
```latex
z_j = \frac{L_j - \operatorname{median}(L)}{1.4826\cdot \operatorname{MAD}(L)}
```
`z < -3` → سعر مشبوه يُعرض للمراجعة البشرية بدل أن يُكافأ.

### 3.3 التقييمات المعدَّلة (حتى لا يتصدر متجر بثلاثة تقييمات 5/5)
```latex
\hat{r} = \frac{v\,\bar{r} + m\,\mu}{v + m}
```
`v` عدد التقييمات، `r̄` متوسطها، `μ` متوسط كل متاجر النادي، `m` = 20.

### 3.4 درجة النادي ومستوياته
```latex
S = T^{\alpha}\cdot\left(\frac{1}{C}\right)^{\beta}\cdot \kappa^{\gamma}\cdot\bigl(1+\delta\,\text{discount}\bigr)
```
`κ` الثقة في البيانات (حداثة ومطابقة)، `discount` خصم النادي. ابتداءً `α=2, β=1, γ=1, δ=0.5` (الموثوقية أهم من الرخص).
| المستوى | الشرط |
|---|---|
| ذهبي | `T ≥ 0.85` و`C ≤ 0.92` |
| فضي | `T ≥ 0.7` و`C ≤ 1.0` |
| تحت المراقبة | داخل النادي لكن يُفحص أسبوعياً |
| يُطرد | `T < 0.6` أو شكويان مؤكدتان خلال 30 يوماً أو بيانات متوقفة 14 يوماً |

### 3.5 ما يراه المشترك
لكل منتج: «الأرخص» و«أفضل قيمة» (PIVOT_PLAN §4) **بين متاجر النادي + المصادر المفتوحة**، شارة المستوى، خصم النادي، وسبب الترتيب
بجملة («أرخص بـ 11% من السوق، توصيل يومين، الدفع عند الاستلام»).

## 4. الكود (يبني على ما بقي بعد الأرشفة)

**خدمة واحدة جديدة `club-service`** (Python/FastAPI — مناسبة للحسابات والبيانات) + جداول:
| الوحدة | المسؤولية |
|---|---|
| `stores` | سجل المتاجر: الحالة (مرشح/مفحوص/عضو/مطرود)، الدولة، الفئات، طريقة الربط، المؤشرات `x_i`، `T`، `C`، `S`، المستوى، تاريخ كل فحص |
| `discovery` | استيراد نتائج البحث (CSV من جلسات الوكيل)، إزالة التكرار بالدومين/الهاتف |
| `connectors` | WooCommerce، Shopify، feed، إدخال يدوي — قراءة فقط، بمفاتيح المتجر مشفّرة |
| `catalog` + `matching` | توحيد المنتجات، المطابقة بالباركود/الموديل/النص |
| `scoring` | معادلات §3 (دوال نقية مختبرة بالكامل؛ الأوزان من ملف) |
| `pricing` | السعر الواصل، القيمة، الثقة، تاريخ السعر، كشف التخفيض الوهمي (PIVOT_PLAN §4) |
| `club` | الخصومات الحصرية، أكواد الأعضاء، التحقق من العضوية عبر auth |
| `monitoring` | مهام دورية: تحديث الأسعار، إعادة حساب `T/C/S`، تنبيه عند الطرد أو الشذوذ |

**الواجهات:** بحث → صفحة منتج بعروض مرتبة → صفحة متجر (لماذا هو في النادي) → «رشّح متجراً» → «بوابة المتجر» (ربط وإدارة الخصم) →
لوحة إدارة البحث (المرشحون، الدرجات، قرارات القبول).

**الاشتراك:** عبر App Store / Google Play (إلزامي للميزات الرقمية داخل التطبيق)، والويب عبر مزود دفع؛ auth يحمل حالة العضوية.

## 5. البحث الذي أنفّذه أنا (الوكيل) — منهج قابل للتكرار
لكل دولة (تركيا ← السعودية ← سوريا)، على دفعات:
1. **مصفوفة الاستعلامات:** 8 فئات × 3 مدن × لغتان = ~50 استعلاماً موثقاً في `docs/research/<country>/queries.md`.
2. **التسجيل:** كل مرشح في `docs/research/<country>/candidates.csv` (الاسم، الرابط، المصدر، تاريخ الاكتشاف، المؤشرات الأولية).
3. **الفحص الأولي:** البوابات الحمراء من صفحات المتجر العامة (قراءة بشرية الطابع، صفحة بصفحة).
4. **عينة الأسعار:** 10 منتجات من كل مرشح ناجٍ، مقابل السعر المرجعي → `C` أولي.
5. **التقرير:** جدول بالدرجات + أفضل 40 + أسباب الرفض → قائمة التواصل الجاهزة لصاحب المشروع.
**حدود صادقة:** ما لا يظهر على الويب العام (متاجر واتساب فقط) يحتاج ترشيحاً بشرياً؛ اختبار المتسوق الخفي يقوم به إنسان.

## 6. الدخل
- **«نادي معرض» (اشتراك رمزي):** خصومات حصرية + متاجر مفحوصة + تنبيهات + تاريخ أسعار. القيمة قابلة للقياس: «وفّرت هذا الشهر X»،
  وهدفنا أن يتجاوز توفير المشترك قيمة اشتراكه بوضوح.
- **المتاجر:** الانضمام مجاني في البداية (نحتاجهم)؛ لاحقاً باقة ظهور مموَّل موسومة لا تغيّر الترتيب.
- **قاعدة:** لا متجر يشتري مكاناً في النادي؛ الدخول بالدرجة فقط.
